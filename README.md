# Таблица с пагинацией

Таблица для отображения больших наборов данных со следующими возможностями:

- Постраничная загрузка данных (ленивая загрузка при скролле)
- Выбор элементов (одиночный или множественный)
- Поиск по значениям
- Сортировка элементов перетаскиванием (Drag & Drop)
- Сохранение состояния на сервере

## Технологии

- Фронтенд: SolidJS
- Бэкенд: Express.js

## Установка и запуск

1. Установите зависимости:

```bash
npm run install-all
```

2. Запустите проект в режиме разработки:

```bash
npm run dev
```

Сервер будет запущен на порту 5000, а клиентское приложение на порту 3000.

## Функциональность

- Список содержит 1 000 000 элементов
- При скролле подгружается по 20 элементов за раз
- Элементы можно выбирать с помощью чекбоксов
- Для поиска используйте поле ввода вверху страницы
- Для изменения порядка перетащите строку за иконку в колонке "Порядок"
- Выбранные и отсортированные элементы сохраняются между перезагрузками страницы

## Деплой на GitHub Pages

```bash
npm run deploy
```

## Структура проекта

- `server.js` - серверная часть на Express.js
- `client/` - клиентская часть на SolidJS
  - `src/components/ItemTable.tsx` - основной компонент таблицы
  - `src/api.ts` - сервис для работы с API
  - `src/types.ts` - типы данных
